Multi-POD dashboard

If you run more than one Orbiter site — client projects, a personal blog plus a company site, whatever — Pods gives you a linked overview of every pod this admin server knows about, without switching terminals or ports.

Where to find it

Admin-only. Appears in the sidebar as Pods once you're logged in as admin.

What it shows

One card per linked pod: collection count, last-modified date, and the full filesystem path. The pod you're currently browsing is marked current and can't be unlinked.

Linking a pod

Paste the path to another .pod file and click Link. It doesn't move or copy anything — this just adds the path to a list stored in the current pod's own meta, so the dashboard knows where to look. Unlink removes it from the list the same way, and doesn't touch the other pod's file.

Scope

This is a this-server overview: it lists pods reachable from the machine running this admin instance, not a hosted directory of every Orbiter pod anywhere. For switching between pods that live on different machines entirely (a freelancer with five client servers), the Desktop app is the better fit — a native multi-window experience for that is on the roadmap.
